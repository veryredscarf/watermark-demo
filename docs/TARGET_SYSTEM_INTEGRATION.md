# 目标业务系统接入设计（待审阅）

版本：0.1；关联 R-02、R-03、R-04、R-06、R-09、R-13、R-16。用户提供的业务系统截图仅作为界面结构参考；截图可能包含真实业务信息，不复制进仓库，也不作为水印识别成功率样本。用户目前无法提供业务系统源码，当前交付范围是可接入的 Vue 3 SDK 与虚构数据验证页；R-16 的真实系统接入验收仍待源码或正式接入点。

## 1. 首批页面与覆盖边界

截图呈现宽屏管理后台：顶栏、左侧导航、页签、查询表单、操作按钮、数据表格、底部分页和较大的空白内容区。SDK 验证页按该结构使用虚构数据搭建；它只验证接入接口、覆盖策略与交互兼容性，不能替代实际系统验收。实际系统的 Vue 3 源码、路由、弹窗挂载方式和服务端权限链路仍待核对。

水印必须在运行中的业务页面生成。可见水印重点覆盖受保护的查询条件、工具栏、表格数据区和内容空白区；不能只出现在空白处而让数据行可被无水印截取。暗水印候选图块覆盖同一受保护视口，并分别验证顶栏、侧栏、弹窗、抽屉、全屏容器和滚动后的可见区域。导航区是否显示可见文字由视觉与业务验收决定；涉及数据的区域不能因此留白。

## 2. Vue 3 代码级接入点

1. 在业务系统的应用外壳或受保护布局中挂载一次 `WatermarkHost`，由路由元数据或业务页面配置选择策略。页面销毁、退出登录、切换租户和资源时更新或清除租约；禁止从截图右上角显示的用户名推断可信身份。
2. 受保护内容接口在服务端认证、资源授权和签发租约后返回内容与水印数据；高敏感数据签发失败时服务端不返回内容。Vue 适配层只消费该响应，服务端保留明暗码映射和密钥。
3. 可见层使用文本/SVG 平铺，暗层使用 Canvas 图块。两层均设置 `pointer-events: none`、`aria-hidden`，不进入焦点顺序。绘制参数从租约与已批准策略获得；暗图块、透明度和间距在实验前冻结，不把候选值写死为已验证配置。
4. 若业务主容器有 `transform`、裁剪或独立滚动，水印宿主需挂到合适的顶层节点并跟随受保护区域的边界。对 Teleport 到 `body` 的弹窗/抽屉、原生全屏和同源 iframe 分别设计挂载；跨源 iframe 不能由本 SDK 直接覆盖，必须由其所属系统接入。使用 ResizeObserver、路由/主题事件和节流重绘处理尺寸变化，避免持续定时绘制。
5. 打印、导出和直接 API 获取是独立内容路径，分别执行权限及水印策略；页面叠层不能替代这些路径的服务端控制。

## 3. 该页面的验收用例

- 在真实运行页面检查查询输入、下拉、日期控件、搜索/重置、操作按钮、表格行链接、横向/纵向滚动和分页；水印不得拦截交互或遮蔽关键文本。
- 对页面顶部、表格数据区、空白区、弹窗/抽屉和滚动后的区域留原始截图，检查可见码覆盖、暗码 T1 解码和明暗主题可读性。数据行的小范围裁剪单列为风险样本；在未通过前不得宣称这种局部截图可恢复。
- 在 1366×768、1920×1080、200% 缩放及实际业务常用视口复验；记录浏览器版本、设备像素比、系统截图方式、页面状态和租约。原图失败必须先修复，再进入真实 A→B→C 转发实验。
- 用户提供的参考截图不能替代带真实运行租约的原始截图，更不能替代两次非原图转发后的 C 端文件。

## 4. 接入前必须核实

业务系统源码或 SDK 接入点、Vue/路由和组件库版本、弹窗与全屏实现、受保护内容 API 与权限链路、目标浏览器、页面数据分级、打印和导出规则。当前只在本仓库实现可接入 SDK 和虚构数据验证页；拿到源码或正式接入点后先做只读评估，再更新组件位置和接口契约，完成 R-16 真实系统验收。用户确认方案前不写功能代码。
